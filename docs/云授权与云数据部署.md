# 仙尘云授权与云数据部署

## 安全边界

仙尘采用机器绑定卡密、Ed25519 签名、Worker 文件完整性校验、云端短期租约和云端吊销组成防护链。任何客户端程序都无法承诺“绝对不可破解”；本方案的目标是提高篡改成本、让泄露授权可及时失效，并保留可审计证据。

防护不得用于反向攻击、破坏他人设备或收集与授权无关的隐私信息。云端只需记录机器码摘要、授权序号、插件版本、校验结果、时间与必要的请求审计信息。

## 云授权

设置环境变量 `XIANLV_LICENSE_CLOUD_URL` 后，插件会向该 HTTPS 地址发送授权校验请求。远端地址必须使用 HTTPS；只有本机回环地址在开发测试时允许 HTTP。

可选环境变量 `XIANLV_LICENSE_CLOUD_TOKEN` 用于服务到服务鉴权。该令牌不得写入源码、公告或玩家数据库。

请求为 JSON：

```json
{
  "product": "xianlv-bee-plugin",
  "version": "2.2.1",
  "machine": "机器码",
  "serial": "12位授权序号",
  "license": "完整本地签名卡密",
  "license_expires_at": 0,
  "challenge": "本次随机挑战"
}
```

成功响应为：

```json
{
  "lease": "XCL1.由仙尘授权私钥签名的短期租约"
}
```

租约必须绑定 `product`、`machine`、`serial`、`challenge` 和本地卡密到期时间。建议租约有效期为 6 至 12 小时，且绝不能超过本地卡密有效期。

云端明确返回拒绝、吊销或签名不正确时，插件立即拒绝启动并删除离线租约。只有连接超时、限流或服务端临时故障时，才允许继续使用尚未过期且签名有效的短期租约；租约过期后严格停用。

## 云数据库

设置 `XIANLV_CLOUD_DATABASE_DSN` 后，Bee 运行时会使用 PostgreSQL 云数据库，例如：

```text
postgres://user:password@host:5432/xianchen?sslmode=require
```

一旦设置该变量，连接失败会阻止插件启动，不会悄悄回退到本地 SQLite，以免同一群服产生两套玩家数据。未设置时继续使用 `plugin_data/仙尘/data/xianlv.db`。

正式切换必须先停止写入、备份本地库、完成一次性迁移并核对玩家数、背包数量、货币总额和关键关联表，再设置云端连接并启动。不得在本地库仍持续写入时直接切换。

## 吊销与审计

云服务至少需要支持以下状态：有效、暂停、吊销、到期。建议按授权序号唯一约束，并记录最后机器码、首次与最后校验时间、失败原因、来源地址摘要和操作者，不保存群聊正文或玩家背包内容。

发现卡密多机复用、伪造签名、篡改程序或高频探测时，可暂停或吊销授权并保留审计记录。误判时应由主人核对授权序号后人工恢复。
