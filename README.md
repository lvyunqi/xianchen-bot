# dengxian-bot

修仙文字游戏「仙尘」插件仓库。

## 分支结构

| 分支 | 说明 |
| --- | --- |
| `main` | 仓库主干：文档与仓库配置 |
| `xianchen` | 仙尘服务端源码（v2.2.2，作者：随缘），解压自 `仙尘源码-v2.2.2.zip` 并整理至分支根目录 |
| `develop` | 日常开发分支，基于 `xianchen` |

## 关于仙尘

面向 QQ 开放平台官机与 Bee 框架的 32 位修仙文字游戏插件：玩家可在群聊或好友私信中入道、修炼、结缘、探索、战斗、经营仙府与宗门。详细文档见 `xianchen` 分支下的 `README.md` 与 `docs/`。

## 备注

- 原始源码压缩包 `仙尘源码-v2.2.2.zip` 已从工作区移除，仍保留在 git 历史提交 `2cc9f14` 中，可随时找回。
- 构建方式：安装 Go 与 Zig 后，在 `xianchen`/`develop` 分支运行 `.\build-x86.ps1` 生成 Windows x86 DLL。
