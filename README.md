# 仙尘

作者：随缘  
版本：2.2.1

面向 QQ 开放平台官机和 Bee 框架的 32 位修仙文字游戏插件。玩家可在群聊或好友私信中入道、修炼、结缘、探索、战斗、经营仙府与宗门，并使用 257 项核心无前缀指令及签到、管理等系统入口。

## 安装

1. 将 `build/仙尘.dll` 加载到 Bee 插件管理器。
2. 首次启用时插件处于未授权状态。点击插件“设置”，授权窗口会直接显示本机机器码。
3. 将机器码交给作者随缘签发卡密，在授权窗口粘贴完整卡密并点击“验证并激活”，无需编辑任何文件。
4. 授权窗口自动保存授权并跳转到本地数据后台，插件同时创建数据库和默认游戏数据。

需要云端吊销与云数据库时，按 [云授权与云数据部署](docs/云授权与云数据部署.md) 设置 `XIANLV_LICENSE_CLOUD_URL` 和 `XIANLV_CLOUD_DATABASE_DSN`。未设置时保持本机签名授权与 SQLite 数据库；设置云数据库后连接失败会停止启动，不会静默写回另一份本地存档。
5. 群聊和好友私信默认使用 QQ 开放平台原生 Markdown；不填写自定义模板 ID，失败时自动回退 Bee 普通文本消息。

群聊原生消息调用 Bee 的 `发送群Markdown消息`，好友私信调用 `发送好友Markdown消息`；后台 `message.mode` 可切换为 `text`，`message.native_fallback` 控制失败回退。

## 主人与神令

后台“系统参数”的 `owner.user_id` 用于设置主人开放平台用户 ID；“管理员设置”可增加管理 ID、角色和启用状态。群内神令无前缀，按护法、长老、宗主、仙尊、道祖五级授权，主人自动拥有道祖权限。未授权账号发送神令时保持静默，所有成功、失败及越权操作都会写入神令操作审计。

卡密生成器只构建到 `build/主人工具`，不进入游戏后台或玩家数据包。插件只携带 Ed25519 公钥；卡密被修改、跨机器使用或过期时会拒绝加载并写入本地 `security.log`。程序不执行自动销毁，也不向外部地址暗中发送机器或文件信息。

## 修炼规则

发送 `修炼` 只会开始计时，不会立即增加修为。默认闭关至少 5 分钟，单次最多结算 14 天；重复发送 `修炼` 只显示当前进度，发送 `出关` 才结算。最短/最长时间、基础收益、灵根倍率和仙侣倍率均可在后台修改。

体力基础上限为 100、每分钟自动恢复 10 点；每提升一个大境界，上限永久增加 100 点、每分钟恢复速度增加 10 点，恢复速度不设上限。体力会按在线或离线经过时间自动结算，无需打坐；各境界从零恢复到满值约需 10 分钟。发送 `体力` 可查看当前值、境界加成和常见玩法消耗。

## 活动中心

发送 `活动菜单` 可进入七日目标、境界冲刺、七日福利、开服密令、道友召集、新秀榜和庆典专属玩法。`活动总览` 分页显示进行中、即将开启、已结束、剩余时间以及本人参与和领取状态。奖励领取、密令兑换和邀请绑定均使用数据库事务，同一奖励不能重复领取；普通日常和悬赏会按前置境界从低到高排列并默认定位玩家当前层次。

## 数据后台

独立启动方式：

```powershell
go run ./cmd/server
```

访问 `http://127.0.0.1:8088/admin`。后台提供动态菜单、仪表盘、内容审核、系统监控和完整游戏数据管理；地图、竞技段位、阵法、符箓、傀儡、秘境争夺、传承、悟道、仙魔战场、灵根进化、渡劫心魔、合体技、仙药、法宝炼化、天机、灵脉、宗门战争、仙缘奇遇、宇宙星河均有独立页面。地图后台可修改地点、区域、相邻路线、进入境界、怪物和 Boss；静态模块首次安装至少生成 1000 条唯一修仙数据，支持图片上传、JSON 与 Excel 导入导出。

玩家提交的 BUG 会记录自动初审、诊断、处理方式、处理结果和完成时间。只有命中已登记玩法的标准配置缺失时，系统才会事务化补齐缺失内置数据；玩法建议只进入运营评审，不会依据玩家文字自动修改源码、经济、权限或发放物品。

## 构建 DLL

安装 Go 和 Zig 后运行：

```powershell
.\build-x86.ps1
```

脚本会生成 Windows x86/PE32 DLL，并把 Go Worker、管理后台和 Logo 嵌入单个 DLL。
